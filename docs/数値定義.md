## v58の食卓企画・案内

数値は本作向けの初期調整値であり、人による満足度の最適値を検証したものではありません。

| 項目 | 初期値・方式 | 目的・検証 |
|---|---|---|
| 企画の数 | 4企画×2つの用途、同時1件 | 管理負担を抑え、商品を異なる目的で組み合わせる。未参加でも通常経営に損失なし |
| 招待条件 | 日6/16/31/46 または会社Lv3/6/9/12 | 序盤後から節目に届く。日付とLvはOR条件、締切なし |
| 提出 | 異なる完成品2種類を各1個 | 通常ロットの期限・保護・予約を守る。企画提出の追加資金・行動枠なし |
| 用途適合 | 要望2タグ、各30点、合計最大60 | タグは2品の集合。重複タグで点を水増ししない |
| 味の違い | 双方に他方にないタグがあれば14点、それ以外6点 | SS同士や高価な食品の一律加点なし |
| 届け方 | 要望と一致で14点、不一致0 | 箱／食卓。どちらが適するか事前表示 |
| 品質 | 2品の品質ランク整数合計、0〜12点 | 品質に価値を残しつつ用途との適合を上位に置く |
| 評価 | 85/65/40点以上で4段階 | 点数と内訳は抽選せず、プレビューと提出で同一関数 |
| 初回報酬 | 20＋floor(点数÷5)研究P、各商品熟練＋3 | 1企画につき1回。再挑戦は最高献立だけ更新。永久倍率・通貨追加なし |
| 試食原価 | 実消費ロットの各単位原価の合計 | 当日の営業損益から1回控除。現金の再支出・販売売上への混入なし |
| 一括準備 | 使用可能な完成品在庫1個まで | 通常の費用・枠、共通workJob。既に在庫があれば追加生産なし |
| 次の操作 | 現在の1バッチに必要な最初の未達工程 | 未来の全工程は概算として折り畳む。数量1の不足も保持 |
| 品質の案内 | 現在の実消費ロットでcraftPlan | 素材未確定の確率を表示しない。標準化の保証は素材上限内 |
| 更新 | ルール2.3.0・コンテンツ58.0・スキーマ3 | 2.2.0から空の企画状態のみ追加。二重報酬・表示での乱数更新なし |

## 次の調整で確認すべきこと

- 最適に近い準備をする自動方針では資金が増えやすい。厳しい破産ゲームではなく成長の体験を優先した初期値。
- 確定保証が増えた後、量産・丁寧を選び分ける頻度が十分あるかは、人のプレイで確認する。
- 操作数には自動テストの設定操作も含む。人のタップ数や所要時間に換算しない。
- 高級路線は高品質契約の実績、研究路線は正式レシピ、地域路線は進出と地域納品が評価に反映される。
- 新たな恒久倍率、リアル時間待機、ログイン義務は採用しない。

- 求人の価格・人数・保証は初期調整値。採用費込みの費用感、不要な大量採用、職種指定の分かりやすさは人のプレイで確認する。
- 再建支援は通常経営の報酬より有利な稼ぎ方になっていないか、意図的な資金消費と初心者の失敗を分けて検証する。

- 食卓企画の選択が自分の工夫に感じられるか、点数の意味と次の変更候補が伝わるかを人のプレイで確認する。毎日参加する必要がないことも確認する。
